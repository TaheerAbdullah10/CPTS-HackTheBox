## About This Repo

Each writeup follows a consistent structure:
- **Overview** — box/module summary
- **Enumeration** — scanning and recon steps
- **Exploitation** — the attack chain used to gain a foothold
- **Privilege Escalation** — path to full compromise
- **Flags** — proof of completion
- **Lessons Learned** — what I'd apply going forward

This is a learning log as much as a writeup collection — mistakes, dead ends, and corrections are documented where relevant, not just the clean final path.
